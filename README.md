# Multiplayer Quiz Games

Първа демонстрация: **Комбо** — 8 рунда срещу NOVA, quiz, тайни оферти и комбинации от плочки.

## Стартиране

```sh
cd sites/combo
npm ci
npm start
```

Отвори http://127.0.0.1:4173. Three.js е включен локално в `dist/vendor`, така че демото работи и без CDN. Шрифтът има системен fallback. След промяна на версията на Three.js копирай `build/three.module.js`, `build/three.core.js` и LICENSE в `dist/vendor`.

```sh
npm test
```

Всички предходни концепции и проучвания са запазени в [docs](docs/). Текущите решения са в [архитектурата](docs/15-architecture.md).

## Статус

Демото е локално срещу компютър, без игрови сървър. Реално P2P лоби не е внедрено. `PeerTransport` е основа за интеграция с вече договорен WebRTC канал, а не завършена мрежова игра. Sites хоства статичния клиент и не управлява мачовете.
